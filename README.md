Privacy Policy — Word Meaning Assistant

Developer: Guilherme Sant’ Anna
Last updated: 2026

Word Meaning Assistant respects your privacy and is designed to operate without collecting personal information.

Information Collection

This extension does not collect, store, transmit, or share any personal information, browsing history, or identifiable user data.

When a user double-clicks a word, the extension sends only the selected word to a public dictionary API (https://api.dictionaryapi.dev
) to retrieve its definition, phonetic transcription, and example usage.

No personal identifiers, user accounts, or browsing activity are collected.

Data Storage

This extension does not store any user data locally or remotely.

Data Sharing

No personal data is shared with the developer or any third parties.

The only external communication is with the dictionary API, and only the selected word is transmitted to retrieve its meaning.

Security

This extension does not access sensitive information such as:

• passwords
• cookies
• browsing history
• personal identifiers

Changes to this Policy

If the extension functionality changes in the future, this privacy policy will be updated accordingly.
